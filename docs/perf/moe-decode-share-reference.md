# grouped EXL3 mul24 の行共有実験（参考値）

2026-11-08、R9700 gfx1201 1 枚、ROCm 7.14、Release、`bench_exl3_int8_grouped`。Flash Next 形状の合成データ（hidden 2560、intermediate 640、512 expert、top-10）、3 回 warmup、各 20 回、`/tmp/r9700.lock` を保持し単独実行。数値は gate と down の別々の launch の平均時間の和で、モデル全体の時間ではない。偏りありは benchmark の expert 重み `1/(i+1)`。1 回ずつの測定であり、分散は評価していない。

基準は d4209ae の 32 行共有。対照案は既存のレジスタ内共有を 64 行に拡大し、LDS への重み展開は行っていない。対照案は性能低下のため採用していない。表は FP16 活性 / INT8 活性、単位 ms。空欄は未測定。
