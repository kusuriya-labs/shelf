# Hy4-Flash Engram 再量子化の実モデル評価

## 条件

現行の FP8 E4M3 と BF16 row scale の表を復号した値を基準に、学習済み codebook で再量子化した。元の BF16 表から直接量子化した評価ではない。scale は行単位、`lloyd4_w32` のみ 32 要素単位で 3 回適合し、FP16 に丸めた。`lloyd4_w32` は 32 要素単位で学習した codebook を用いた。各モード・各列で KV と内部状態を初期化し、teacher forcing で全位置の logits を比較した。KL は `KL(reference || candidate)`、ΔNLL は candidate − reference。

評価対象は一般 51 列と PopQA 400 問。PopQA は探索 100 問、評価 300 問で、人気度の境界と抽出条件は `/tmp/ngram_q_eval_data/manifest.json` に記録されている。全評価は一度のモデルロードで実行した。identity は量子化のみを省き、量子化時と同じ転送と復号カーネルを通した。

再現条件: GPU は gfx1201 1 枚と gfx1030 2 枚、`ROCR_VISIBLE_DEVICES=GPU-a8e9ddefa2d60f55,GPU-08b2ddcbd6e6b36c,GPU-76a08c022586fed6`、`--max-seq-len 192 --chunk 64`。入力は `/tmp/ngram_q_step2_hy4/sequences.jsonl`、codebook は `/tmp/ngram_q_step2_hy4/codebooks.json`、生結果と trace は同ディレクトリの `results_fixed.jsonl` と `results_fixed.jsonl.trace.jsonl`、ログは `eval_fixed.log`。集計は `python3 /tmp/ngram_q_step2_hy4/aggregate_fixed.py`。

```bash
ROCR_VISIBLE_DEVICES=GPU-a8e9ddefa2d60f55,GPU-08b2ddcbd6e6b36c,GPU-76a08c022586fed6 build-hy4-eval/shelf-compute hy4 eval-engram \
  --model-dir /home/homelab1/llm-fast-load/Hy4-flash-exl3-4bpw-mul24 \
  --engram-dir /home/homelab1/datapool/rocm-exl3-rdna2/hy4-flash-pilot/engram-e4m3fn \
```

### 微小な差と BF16 丸め

長文と PopQA の各 1 列で `reference + α × (lloyd8 − reference)` を再評価した。これは codebook の bit 数を増やした評価ではなく、誤差の大きさを調べる介入実験である。

| 対象 | α = 1 | α = 0.1 | α = 0.01 | α = 0.001 |
|---|---:|---:|---:|---:|
| 一般・151 位置の平均 KL | 0.27440 | 0.23064 | 0.27003 | 0.25899 |
| PopQA・13 位置の平均 KL | 0.00877 | 0.00616 | 0.00790 | 0.00944 |

α = 0.001 の長文では BF16 丸め後の 927,744 要素中 45,242 要素が reference と異なり、そのうち 44,369 要素は reference の FP8 復号値が BF16 のちょうど中間にあった。行の平均 relative L2 は 0.0754% に下がったが、丸めの中間点では非常に小さい差でも結果が変わる。

別の対照として、reference と候補を先に BF16 に丸めた値の間を α = 0.001 で補間した。この場合の長文の変更要素は 633 個、行の平均 relative L2 は約 0.00000269% だったが、平均 KL は 0.19460 で、layer 1 の expert 集合は 151 位置中 9 位置で変わった。PopQA は KL 0 だった。この実験は BF16 中間点の効果が存在することを示す一方、それだけが KL の残差を説明するとは示していない。さらに小さな差の増幅、expert 処理のバッチ依存性、他の離散演算や実装上の問題を切り分ける必要がある。`/tmp/ngram_q_step2_hy4/interp_results.jsonl`、`tie_results.jsonl`、`tie.log` に生データを保存した。

### バッチの影響

同じ長文の先頭位置と正解トークンについて、64 位置をまとめて評価した reference の NLL は 5.13866、先頭 1 位置のみを評価した reference の NLL は 3.83543 だった。行数によって expert と線形演算の実行経路も変わるため、両者の差を単に文脈の効果と見なせない。64 位置という行数を保ったまま後続トークンを別の値に変えた対照では、先頭の NLL はどちらも 5.13866 だった。これは調べた例で後続内容による変化がなかったことを示すが、バッチの行数による大きな差の原因や、全位置で因果性が成立することの証明にはならない。生データは `/tmp/ngram_q_step2_hy4/first_only_results.jsonl` と `causal_results.jsonl`。

本評価の数値は指定された `chunk=64` の実測結果である。バッチ行数による影響と微小差の増幅は未解明であり、今回の再測定のみから Engram 再量子化の固有の品質を断定しない。
